# blinkit-_Sales_Dashboard
blinkit Sales Dashboard Using Power BI
This Power BI dashboard to analyze the blinkit Sales data. blinkit is an Indian online grocery delivery company. Therefore I tried to analyze those data to get total sales, average sales, average rating, and number of items, etc. 📊 

The Power BI dashboard for blinkit provides key insights into sales and inventory performance.
✨ Total Sales: $1.20M, with an average sale of $141 per item.
✨ Top-Selling Categories: Fruits & Nuts, Snack Foods, and Household Items.
✨ Outlet Performance: Supermarkets and grocery stores drive major sales, with Tier 3 outlets leading.
✨ Sales by Size: Medium and large outlets contribute the most revenue.
✨ Trends: Sales peaked at $205K in the best year, with steady growth over time.
